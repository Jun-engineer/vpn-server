How to use this VPN controller

  1. Click any action button. On first use you will be prompted for your API key. The API URL is already configured, and the key is saved in this browser.
  2. Use Start VPN when you need the server. After starting, select Check Status until the message switches from “VPN warming up…” to “VPN available”.
  3. Auto-stop policies handle shutdowns, so there is no manual Stop button. Use Forget saved API key if you need to switch credentials.
